# Contributing

This public repository is an exported distribution of Ranch.Bot's maintainer-controlled monorepo
development. It is not the development source, and it does not accept public issues or pull
requests.

## Feedback and proposed changes

Send feedback and proposed changes to [support@ranch.bot](mailto:support@ranch.bot). Do not open a
GitHub issue or pull request here. Include the package version (`ranchbot-mcp --version`), what you
expected, what happened, and the smallest reproduction you can share. Never include tokens,
credentials, or customer records.

## How changes reach this repository

Maintainers own integration, review, export, and releases. An accepted change is implemented and
reviewed in the private monorepo, exported as a reviewed commit, and released through the
maintainer's release process. A source update in this repository or a merge does not by itself
establish that a new version is available on npm or in the MCP Registry.

There is no contributor license agreement to sign because there is no public contribution path.
